===============================================================
  USED BY THE CONTROL CENTRE
===============================================================

create-owner                                   live (401)
---------------------------------------------------------------
  Creates the login for a new company owner after you approve
  their request. This is the engine behind the Approve button.

  POST, with headers:
      apikey: <anon key>
      Authorization: Bearer <your session token>
  Body:
      { "email": "...", "invitation_id": "..." }
  Returns:
      { "email", "password", "app_url" }

  If "password" comes back missing, that account already
  existed — the panel shows this as "already registered"
  rather than an error.


platform-admin-api                             live (401)
---------------------------------------------------------------
  Handles customer files. Called through the Supabase client
  rather than by URL:

      sb.functions.invoke('platform-admin-api', {
        body: { action, file_id, reason, confirmation }
      })

  action: "storage_signed_url"
      Returns { url } — a temporary private link to open or
      download a customer's file.

  action: "storage_delete"
      Permanently deletes a file. Requires
      confirmation: "DELETE FILE" exactly, or it refuses.

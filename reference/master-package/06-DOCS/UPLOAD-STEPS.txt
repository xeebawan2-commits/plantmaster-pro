===============================================================
  WHAT THE LOCK ACTUALLY DOES
===============================================================

  Three layers, so it cannot be worked around casually:

  1. The six paid fields are disabled in the form.

  2. On save, the app checks the plan again and strips the
     branding values out of what gets sent. So even if
     someone re-enables the fields using browser developer
     tools, nothing branded is saved.

  3. On login, branding is only applied if the plan allows
     it. So if a customer stops paying and you untick the
     feature, their logo and colours stop appearing — but
     their address, contact details and footer stay intact.

  Note: this is enforced in the app, not in the database. A
  determined technical person could still write to the
  database directly. Proper enforcement is a database rule,
  which is worth adding once this is earning money. For
  plant managers, this is fine.


===============================================================
  ONE LIMITATION TO KNOW BEFORE YOU SELL
===============================================================

  The per-company editor can only take a feature AWAY, not
  add one. So ticking branding for a single company whose
  package does not include it will NOT switch it on.

  For a one-off customer who wants to pay for branding:
    - move them up to Professional, or
    - copy their package, tick branding on the copy, name it
      something like "Essential + Branding", and move that
      one customer onto it.

  Also: this brands the app INSIDE, and brands their reports
  and documents. It does NOT change the icon and name on the
  phone home screen — that is still PlantMaster Pro for
  everyone. Sell it as "your branding inside the app and on
  your reports", never as "your own app".

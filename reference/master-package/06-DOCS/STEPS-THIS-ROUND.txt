---------------------------------------------------------------
  STEP 1 — RUN THE SQL   (2 minutes)
---------------------------------------------------------------

  File:  10-COMPANY-FEATURES.sql
         (in the upload-admin-panel folder)

  Supabase dashboard > SQL Editor > paste the whole file > Run.

  Safe to run more than once. It will print a short table at
  the end; all three rows should say "created" or "removed".

  What it does:

  a) Creates company_feature_grants — the missing half of the
     system. Until now there was only a "blocks" table, which
     is why the panel could take a module away but never add
     one.

  b) Removes an old restriction on the blocks table. Its
     feature column only accepted five names (gemini,
     deep_search, vision_scanner, condition_analysis,
     uploads). Blocking anything else was failing silently.
     All 21 modules work now.

  c) Adds organization_effective_features() — one function
     that works out what a company can actually use:

         package features
           + extras granted to that company
           - things blocked for that company

  d) Sets the security rules: only you can change these;
     a company can read its own entitlements; nobody can
     grant themselves anything.

---------------------------------------------------------------
  STEP 3 — SWITCH THINGS ON
---------------------------------------------------------------

  FOR EVERYONE ON A PACKAGE:
      More > Plans & packages > open the package
      > tick the modules you want
      > tick "Company profile & branding"
      > Save

  FOR ONE COMPANY ONLY (this is the new part):
      Companies > the company > Edit
      > Modules for this company
      > tick anything you want to ADD for them
      > untick anything you want to TAKE AWAY
      > Save

  Every module is now tickable. A module their package does
  not include says "not in their package" — tick it anyway
  and they get it. Once saved it says "extra for this
  company".

  This is how you sell an add-on without making a whole new
  package.
